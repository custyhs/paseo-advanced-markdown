# Advanced Markdown 0.1.4

Ships the current math-reading candidate as a tagged plugin build.

- Adds desktop formula action reveal on hover and keyboard focus, keeping the formula geometry stable.
- Adds touch and compact behavior for block formulas: tap the formula to show actions, tap again to hide them, and use Expand to open the inspector.
- Keeps hidden touch actions out of layout and accessibility navigation until disclosed.
- Preserves direct inline formula inspection, source-mode controls, retry controls and Mermaid behavior.
- Includes the previous candidate math improvements: formula size presets, adaptive fitting, higher-density images, inspector fit/reading/zoom controls, and expanded notation coverage.

The plugin still targets official Paseo 0.8.0. No Paseo patch or daemon restart is required.

## Install

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.1.4
```

If already pinned to an older tag:

```bash
paseo plugin remove advanced-markdown
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.1.4
```

`plugin update` continues tracking the installed ref; it cannot advance a fixed
older tag. Clients connected to that host receive the new plugin bundle.

## Validation

Official Paseo 0.8.0 browser checks cover desktop hover/focus, compact and
touch-style tap disclosure, exact-source copy, inspector opening, retained
actions after inspector close, and horizontal formula scrolling without
accidental disclosure. Typecheck, lint, formatting, the official compiler smoke,
and Hermes bundle evaluation passed locally. GitHub Actions gates the release on
Ubuntu.

iPhone device validation for the new tap-disclosure interaction remains pending.
