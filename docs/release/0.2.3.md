# Advanced Markdown 0.2.3

Fixes `Renderer asset resvg.wasm is not prepared` after a plugin reload or cache
loss. Startup now verifies the WASM and MathJax font tables before loading the
renderer, and restores missing or damaged files from bundled offline recovery
data. This also covers local directory installations, whose reloads do not run
the manifest's preparation commands.

- Shares integrity checks and atomic cache writes between installation and startup.
- Recovers the WASM before its first use if the cache was cleared after startup.
- Reuses valid files and retains older assets and the Mermaid worker/browser cache.
- Reports the asset and cache path if recovery cannot write; no runtime downloads
  or dependency installation are introduced.
- Adds regression coverage for cold starts, corruption, simultaneous processes,
  unwritable cache paths, and isolated npm packages after activation moves.

The npm archive includes compressed recovery data because Paseo evaluates plugins
in memory without a reliable installation path. This adds about 1 MiB to the
archive; the complete JavaScript/TypeScript source inventory remains within the
existing package budget.

Supports Paseo app and daemon `>=0.8.0 <0.10.0`. Install from Git:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.2.3
```

For an existing Git installation, if the CLI supports `plugin update --ref`:

```bash
paseo plugin update advanced-markdown --ref v0.2.3
```

The fix passed 15 focused tests, typechecking, lint, and formatting checks on
macOS arm64. Isolated npm packages recovered and rendered real formula/Mermaid
PNGs with the official Paseo 0.8.0 and 0.9.0-beta.2 compilers. The production
plugin was reloaded on Paseo 0.9.2 and rendered simple, fraction, and Chinese-text
formulas without restarting the daemon.

Use v0.2.2 to roll back; that version still requires explicit asset preparation
if its cache is missing. This release changes host-side asset recovery, not the
client layout. Latest iPhone layout and Android UI validation remain pending.
