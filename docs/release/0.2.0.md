# Advanced Markdown 0.2.0

Opens formulas and Mermaid diagrams directly in one viewer and improves reading
long formulas, code lines, and native inline math.

- Click or tap content to open **Preview / Source**, with explicit LaTeX,
  Mermaid, Markdown, and message-fragment copy actions. Removes hover and
  tap-to-reveal toolbars from the conversation.
- Adds fit and zoom controls, content-sized formula dialogs, and source/retry
  states in the viewer.
- Supports mouse dragging on overflowing formula images and code blocks.
  Code blocks offer **Select text / Drag to scroll**; copying preserves the
  original source, indentation, spaces, and final newline.
- Fixes footnote definitions causing an entire reply to fall back to the host
  renderer, leaving formulas unrendered. Footnotes remain readable text.
- Reserves native text-run height for ordinary fractions, sums, and scripts.
  Especially tall formulas become separate blocks, with adjacent punctuation
  kept beside the formula.

Supports official Paseo app and daemon versions `>=0.8.0 <0.10.0`. No Paseo patch
or main daemon restart is required.

## Install or update

For a new installation:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.2.0
```

For an existing Git installation, if your CLI lists `--ref` in
`paseo plugin update --help`:

```bash
paseo plugin update advanced-markdown --ref v0.2.0
```

An older fixed tag does not advance through a plain `plugin update`. Older CLIs
require removing and adding the plugin with the new tag; record settings before
removal because it deletes them. Use v0.1.5 to roll back on Paseo 0.8 or 0.9.

## Validation and limits

Local build, typecheck, lint, formatting, focused regression tests, and Hermes
evaluation passed. The GitHub Actions validation and 0.9 compatibility jobs gate
publication, covering the full test suite and real formula/Mermaid rendering
through official 0.8.0 and 0.9.0-beta.2 compiler/SDK paths.

Official browser checks cover viewer entry, zoom, exact-source copying, drag
scrolling, code text selection, and punctuation. The footnote rendering repair
was checked in the production Electron client. User-provided iPhone screenshots
guided the native layout fixes; **the latest iPhone adjustment has not yet been
retested on a device, and Android UI validation remains pending**. Browser or
Hermes checks do not establish native layout acceptance. Native text selection
may include a zero-width layout character; viewer copy actions use original source.

See the [validation record](../qa/click-viewer.md) for evidence and remaining gaps.
