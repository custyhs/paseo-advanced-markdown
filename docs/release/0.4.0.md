# Advanced Markdown 0.4.0

Keeps formula rendering and its viewer while reusing Paseo's built-in Mermaid
viewer and syntax-highlighted code blocks by default, including in messages
that also contain math. Both app and daemon now require **Paseo >=0.13.0**,
without an upper version limit.

## Changes

- New installations enable math and leave enhanced Mermaid, code scrolling and
  tables off. Existing saved choices are preserved. Those optional viewers
  remain available in Settings → Plugins → Advanced Markdown.
- Mermaid and code blocks inside quotes and lists retain their parsed content
  and language when passed to Paseo's public Markdown component. Unclosed,
  empty or over-budget math/Mermaid fences retain readable source fallbacks.
- Client UI imports use the public `/client/ui` entry. Formula sizing,
  scrolling, LaTeX copying and asset recovery remain available.
- Documentation removes obsolete streaming limits and distinguishes plugin
  rendering from the host's message actions.

## Separate host fix

**This plugin release alone does not restore Copy, Fork or work duration in
unpatched Paseo clients.** The host's timeline projection replaced assistant
messages with plugin rows, losing the identity used by reply actions and turn
collapse. The [separate host patch](https://github.com/custyhs/paseo/commit/74c11e85a86b453d3a7201698dc122fdfb6fca9b)
keeps the assistant message and renders plugin output inside its body.
It also benefits existing transformer plugins without a new SDK contract.

Mixed prose and inline math still use the plugin's Markdown engine; this is not
a complete migration to the official renderer. See [integration boundaries and
validation](../qa/host-integration.md).

## Validation

- 108 targeted plugin tests cover parsing, settings, block reconstruction and
  version gates. Build, typecheck, lint and real Hermes evaluation passed.
- Package validation covers official Paseo 0.13.0 and 0.14.0, including real
  formula/Mermaid rendering, relocation and offline asset repair. The final
  0.4.0 tarball is checked with the minimum supported 0.13.0 runtime.
- The patched 0.15.0-beta.1 host passed unit, Find browser and eight host E2E
  checks. Actual plugin integration passed at 1100px and 390px, including full
  source copy, reply actions, formula viewing, native Mermaid/code and optional
  enhanced controls.
- Browser checks used Chrome on macOS. Native iOS/Android, Electron and Windows
  remain unverified. Phone-width browser checks are not native device checks.

## Update

For an existing npm installation:

```bash
paseo plugin update advanced-markdown --version 0.4.0
```

For an existing Git installation:

```bash
paseo plugin update advanced-markdown --ref v0.4.0
```

Paseo 0.11–0.12 users should stay on v0.3.2; Paseo 0.8–0.10 users should stay
on v0.3.0. Plugin updates preserve saved settings.
