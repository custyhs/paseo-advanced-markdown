# Advanced Markdown 0.4.1

Removes the Chrome-based Mermaid renderer. All Mermaid diagrams now use Paseo's
built-in renderer and viewer. Formula rendering continues to use MathJax and resvg
with bundled assets, without a browser. Both app and daemon require **Paseo
>=0.13.0**, without an upper version limit.

## Changes

- Removes **Enhanced Mermaid viewer**, its PNG rendering RPC, Mermaid CLI worker,
  browser downloader, and Chrome runtime preparation. A saved `mermaid: true`
  preference is ignored; math, code scrolling, table, and sizing preferences are
  preserved.
- npm installation prepares only bundled formula assets. Git installation uses
  the committed lock with `npm ci --ignore-scripts`, builds the plugin, then
  prepares those assets. Activation and rendering install no additional software.
- Removes the plugin's diagram PNG/source viewer. Mermaid diagrams, including
  diagrams beside formulas, use Paseo's own viewer and controls.
- Keeps existing formula assets and leaves browser/worker caches from older
  versions untouched. They are no longer used by this version.
- Adds a registry overview and updates documentation for the official
  [Paseo plugin directory](https://paseo.sh/plugins).

## Registry review

The previous migration hold, [getpaseo/plugins#33](https://github.com/getpaseo/plugins/issues/33),
reviewed version 0.2.6 and identified installation-time browser download and
execution. This version removes that execution path and the browser dependency
instead of offering a later browser setup step. A corrected published artifact
must be reviewed before directory listing; these changes do not establish approval.

## Validation

- Build, typecheck, lint, and formatting checks passed.
- 170 targeted tests passed across parsing, host delegation, old settings, viewer
  layout, caching, startup recovery, and packaging. Mermaid definitions above the
  old 32 KiB limit stay with the host, including beside formulas.
- The generated npm package passed an official Paseo 0.13.0 compiler smoke:
  production-only installation, offline preparation with network and child-process
  APIs blocked, relocation, real formula PNG rendering, and recovery after removing
  or corrupting asset files. Its fresh cache contained only `assets/`.
- All 21 production dependency entries have registry URLs and integrity locks.
  The package contains no Puppeteer, Mermaid CLI, browser worker, or browser
  installation script.
- A real 390px browser check passed against an isolated Paseo 0.15.0-beta.1 host
  with the separate integration fix: formula viewing and exact LaTeX copying,
  native Mermaid SVG beside formulas, and settings without the removed switch.
  Its fresh cache contained only formula assets. Current screenshots are included
  in the package and registry metadata.

The [0.4.0 integration record](../qa/host-integration.md) remains historical
evidence. Native iOS/Android devices, Electron, and Windows remain unverified.

## Update

For an existing npm installation:

```bash
paseo plugin update advanced-markdown --version 0.4.1
```

For an existing Git installation:

```bash
paseo plugin update advanced-markdown --ref v0.4.1
```

Paseo 0.11–0.12 users should stay on v0.3.2; Paseo 0.8–0.10 users should stay on
v0.3.0. Those older releases retain their browser-preparation behavior.

This release does not include the separate Paseo host fix for reply actions and
turn collapse. See [host integration](../qa/host-integration.md).
