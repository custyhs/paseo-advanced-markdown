# Advanced Markdown 0.3.0

Adds optional code-block and table rendering so long lines keep their indentation
and wide tables remain readable on narrow screens. Both modules are **off by
default**; enable them in **Settings → Plugins → Advanced Markdown**.

- **Code blocks** adds horizontal scrolling for ordinary fenced and indented
  blocks. Desktop users can switch between dragging to scroll and selecting text;
  **Copy source** copies the block body without its fence.
- **Tables** keeps readable column widths and scrolls horizontally. **Open table**
  opens the shared viewer with **Preview** and **Source** modes. Links and text
  selection remain available without opening the viewer.
- **Copy Markdown** preserves links, emphasis, inline code, math delimiters,
  alignment, and escaped pipes. Tables inside lists or quotes omit the outer
  container markers; referenced link definitions are included when needed.
  **More → Copy as TSV** copies plain cell text, replacing tabs and line breaks
  inside cells with spaces.
- Turning **Tables** off restores the standard layout in plugin-owned messages
  and closes an open table viewer. During continuous live streaming, appended
  table rows update the open viewer and its copied Markdown.
- Each ordinary code block is limited to 65,536 JavaScript string units,
  including its parsed trailing newline. Each table is limited to 400 cells,
  including headers; multiple tables have separate budgets. A row containing any
  over-budget code block or table stays with Paseo's renderer, including mixed
  rows containing formulas or diagrams.

Thanks to [cmulittlechild](https://github.com/cmulittlechild) for the initial
code-block and table modules in [PR #1](https://github.com/custyhs/paseo-advanced-markdown/pull/1).

The supported app and daemon range remains **`>=0.8.0 <0.12.0`**. CI passed the
Paseo 0.9, 0.10, and 0.11.0-beta.3 compatibility matrix. Targeted regression checks
cover Markdown copying, table budgets, settings, and streamed updates. Sixteen
browser assertions passed with the official 0.11.0-beta.3 client at desktop and
phone widths, including actual clipboard contents, scrolling, and link behavior.
See the [code and table QA record](../qa/code-table-review.md).

The v0.3.0 npm artifact also passed isolated installation with Paseo 0.8.0 and
0.11.0-beta.3: compilation, real formula and Mermaid PNG rendering, relocation,
empty-cache startup, and corrupt-WASM/missing-font recovery without the original
asset files. The production dependency audit reported no vulnerabilities.

Native iOS/Android devices and Windows were not tested. Phone-width browser
checks do not establish native device compatibility. Reopening a completed
historical message as a live row can still close its viewer when the host remounts
the row; continuous live streaming passed.

Install from Git:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.3.0
```

For an existing Git installation with `plugin update --ref` support:

```bash
paseo plugin update advanced-markdown --ref v0.3.0
```

The npm package is `paseo-advanced-markdown@0.3.0`. Use v0.2.6 to roll back on
the same supported Paseo versions; it does not include the optional code-block
and table modules. See [usage and limits](../usage.md) for module settings and
copy behavior.
