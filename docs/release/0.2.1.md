# Advanced Markdown 0.2.1

Prepares Advanced Markdown for npm distribution and community catalog submission.
Formula and Mermaid viewer behavior remains as released in v0.2.0.

- Adds `npm run pack` to produce a public-ready package with prebuilt Markdown
  and MathJax modules, production dependencies, and the pinned Mermaid worker lockfile.
- Distributes the original resvg WASM and MathJax SVG font tables as data assets.
  Preparation and runtime reads verify their size and SHA256; content-addressed
  cache paths survive Paseo's installation move and retain older assets for rollback.
- Checks the complete shipped JS/TS source inventory against the community
  catalog's source budget, including generated modules and declaration files.
- Excludes build tools, host SDKs, and unused MathJax speech/XML dependencies
  from the consumer installation.
- Adds isolated package installation, activation-move, and real formula/Mermaid
  rendering checks for the official Paseo 0.8.0 and 0.9.0-beta.2 compilers in CI.

Supports Paseo app and daemon `>=0.8.0 <0.10.0`. Install from Git:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.2.1
```

For an existing Git installation, if the CLI supports `plugin update --ref`:

```bash
paseo plugin update advanced-markdown --ref v0.2.1
```

Use v0.2.0 to roll back. Custom `PASEO_ADVANCED_MARKDOWN_CACHE` paths must be
absolute. Prepare a local directory installation before reloading it.

The npm artifact attached to this release is separate from npm registry publication
and community catalog admission. See the [package validation record](../qa/npm-package.md)
for artifact checks. Latest iPhone layout and Android UI validation remain pending;
this packaging release adds no device QA claims.
