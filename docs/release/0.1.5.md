# Advanced Markdown 0.1.5

Fixes plugin loading after upgrading Paseo from 0.8.0 to 0.9.0-beta.2.
The previous exact version requirement rejected newer hosts before compilation.

- Supports Paseo app and daemon versions `>=0.8.0 <0.10.0`, including 0.9 betas
  accepted by Paseo's official version validator.
- Adds 20 app/daemon version-gate cases and a separate 0.9.0-beta.2 compiler/SDK
  CI job while retaining the 0.8.0 development baseline.
- Requires real Mermaid browser rendering in both CI smoke jobs.
- Preserves v0.1.4's formula, Mermaid, source-copy, layout and settings behavior.

## Install or upgrade

For a new installation:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.1.5
```

If already installed with an older fixed tag:

```bash
paseo plugin remove advanced-markdown
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.1.5
```

`plugin update` continues tracking the installed ref; an older fixed tag does not
advance to v0.1.5. No Paseo patch or daemon restart is required. Earlier plugin
tags still require exactly Paseo 0.8.0, so they are not a rollback option on 0.9.

## Validation and limits

Local build, typecheck, lint, formatting and the 20 version-gate cases passed.
Official 0.8.0 and 0.9.0-beta.2 compiler/registration smoke checks produced real
formula and Mermaid PNGs, including Chinese bold/boxed math and invalid-input
fallbacks. The 0.9-compiled client passed Hermes evaluation with both runtime
flag configurations. Both Ubuntu CI jobs must pass before publication.

The version range is a compatibility policy, not device QA for every accepted
version. App projection/stream fixtures remain pinned to 0.8.0. This patch does
not add new 0.9 client UI or iPhone/Android device acceptance; see the
[compatibility evidence](../qa/paseo-0.9-compatibility.md).
