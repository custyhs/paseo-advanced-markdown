# Advanced Markdown 0.2.2

Adds three real screenshots to the repository's `images/` directory for the
Paseo plugin catalog: math mixed with prose, the formula viewer, and a Mermaid
release pipeline. The README embeds the gallery, and the npm package includes
the same images.

Screenshots use sample conversations in the official Paseo 0.9.0-beta.2 web client.
Rendering and interaction behavior remains as released in v0.2.1.

Supports Paseo app and daemon `>=0.8.0 <0.10.0`.

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.2.2
```

For an existing Git installation, if the CLI supports `plugin update --ref`:

```bash
paseo plugin update advanced-markdown --ref v0.2.2
```

Use v0.2.1 to roll back. Latest iPhone layout and Android UI validation remain
pending; these desktop screenshots add no device QA claims.
