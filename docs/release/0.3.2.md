# Advanced Markdown 0.3.2

Removes the upper Paseo version limit. Both app and daemon now require
**`>=0.11.0`**, replacing `>=0.11.0 <0.13.0`. Newer Paseo versions are no longer
blocked by the plugin's version declaration.

This release updates the manifest, compatibility gate tests, package metadata,
and installation documentation. It also updates `markdown-it` from 15.0.1 to
15.0.3 to fix excessive parsing time for crafted Markdown link references,
inline HTML, and smart quotes. Plugin rendering and copying features and default
settings are unchanged.

Compiler and package checks cover official Paseo 0.11.0 and 0.12.0. The version
gate also accepts 0.13 and later, but those host versions have not been validated.
The most recent web UI checks remain the [Paseo 0.12 validation](../qa/paseo-0.12-compatibility.md)
from v0.3.1; this release adds no native iOS/Android or Windows validation.

Install from Git:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.3.2
```

For an existing Git installation with `plugin update --ref` support:

```bash
paseo plugin update advanced-markdown --ref v0.3.2
```

The npm package is `paseo-advanced-markdown@0.3.2`. For an existing npm
installation with `plugin update --version` support:

```bash
paseo plugin update advanced-markdown --version 0.3.2
```

Paseo 0.11–0.12 users can roll back to v0.3.1. That release excludes Paseo 0.13
and later. Paseo 0.8–0.10 users should stay on v0.3.0.
