# Advanced Markdown 0.5.0

Adds fork-safe replies. Under the final reply of a completed turn it draws, the
plugin now shows a footer with **Copy turn**, **Show original**, and the turn's
end time. Show original hands the whole turn back to Paseo, so Paseo's own
Copy, Fork, and work duration appear, with formulas as TeX source. Reaching
Copy and Fork no longer needs a patched client. Both app and daemon require
**Paseo >=0.13.0**, without an upper version limit.

## Changes

- Adds the turn footer. **Copy turn** copies the turn's replies joined by blank
  lines, the text Paseo's own Copy produces for a native turn. **Show
  original** hands the turn back to Paseo; a composer pill ("Original view ·
  N turns") restores plugin rendering, and so does a reload.
- Draws plain replies that precede a plugin-drawn answer in the same turn, so
  Paseo never shows a Fork anchored before the final answer. A reply without a
  message id is keyed by its exact text; when a short or repeated one cannot be
  claimed, the footer adds a warning that Paseo's Fork below stops before this
  answer.
- Reads each open chat's timeline through Paseo's API to find turn boundaries
  and copy turns. The index lives in memory only.
- Adds the host-scoped **Show original for Fork** switch to the Modules
  settings, on by default. Off restores the 0.4.1 behavior exactly.
- Adopts the host footer opt-in of
  [getpaseo/paseo#9253](https://github.com/getpaseo/paseo/pull/9253) (open, in
  no release): a host that keeps its own footer for plugin-rendered replies
  shows Paseo's footer under typeset replies with no setting change, and the
  plugin draws no footer and reads no timelines there.
- Module-setting changes now re-project conversations already on screen;
  reopening the conversation is no longer needed.

## Compatibility

- Better Paseo: its **Plugin markdown for replies** must be off for Paseo's
  Fork to appear; the first Show original of a session shows a toast saying so.
  With it on, replies this plugin declines go to Better Paseo, and Fork stays
  unavailable.
- Collapse turns: on Paseo 0.16.0, a turn whose plain replies the plugin draws
  folds with its answer visible, and Show original keeps it folded. On 0.15.x
  such a turn does not fold until Show original.
- Paseo 0.13.x: turns started by heartbeats or agent messages can still show an
  early-anchored Fork before Show original.
- Known limitations — the first-load window, unprotected turns, identical
  plugin-drawn replies switching together, late duplicates, read-only subagent
  panes, and a renamed #9253 field — are listed in the
  [README](../../README.md#reply-actions-and-compatibility).
- The separately maintained
  [host patch](https://github.com/custyhs/paseo/commit/74c11e85a86b453d3a7201698dc122fdfb6fca9b)
  remains an alternative to Show original; see
  [host integration](../qa/host-integration.md).

## Validation

- Build, typecheck, lint, and formatting checks passed, plus the official Paseo
  0.13.0 compiler smoke with v0.8.0 projection fixtures and the Hermes bundle
  smoke (`npm run smoke:hermes`, React Native 0.81 Hermes, default flags and
  `-Xes6-class`). The generated npm package passed `smoke:package` against
  official Paseo 0.13.0, 0.14.0, and 0.16.0 runtimes, and `npm audit` reported
  no production vulnerabilities.
- 76 targeted tests passed across seven files: `tests/math-settings.test.ts`
  (19), `tests/reply-turns.test.ts` (5), `tests/reply-co-ownership.test.ts` (9),
  `tests/reply-decision.test.ts` (6), `tests/reply-store.test.ts` (24),
  `tests/reply-runtime.test.ts` (11), and `tests/reply-footer-state.test.ts` (2).
- The pinned-host pipeline check
  ([`scripts/qa/reply-actions.mjs`](../../scripts/qa/reply-actions.mjs), run as
  `npm run host-source && npm run qa:reply-actions`) passed 13 cases on each of
  official Paseo v0.15.3, v0.16.0, and the head of getpaseo/paseo#9253
  (`ffa02c5d81970c6ffbda9d3802287ed9f06648d6`). On the PR host, every formula
  turn shows Paseo's footer under the typeset reply without Show original.
- Real-client QA ran on an isolated official Paseo 0.16.0 daemon with Claude
  Code, Codex, and Better Paseo 1.6.0, at 1100 and 390 pixels: 11 of 12 check
  groups passed, and the daemon-restart warning check was partial because the
  reloaded Claude replies kept their message ids. Not checked: Electron, iOS,
  and Android. See the [QA record](../qa/fork-safe-replies.md).

## Update

For an existing npm installation:

```bash
paseo plugin update advanced-markdown --version 0.5.0
```

For an existing Git installation:

```bash
paseo plugin update advanced-markdown --ref v0.5.0
```

Paseo 0.11–0.12 users should stay on v0.3.2; Paseo 0.8–0.10 users should stay
on v0.3.0.
