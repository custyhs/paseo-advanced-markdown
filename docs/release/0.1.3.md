# Advanced Markdown 0.1.3

Fixes six rendering and lifecycle regressions in 0.1.2:

- Stop and timeout reclaim the Mermaid CLI and its Chrome descendants without terminating unrelated browsers.
- Chinese bold text renders instead of falling back as invalid TeX.
- Missing fonts and renderer failures can be retried, including inline formulas; installing a font recovers without clearing the client cache manually.
- Font parsing and glyph coverage are validated before rasterization, preventing successful images with missing annotations.
- `\boxed{…}` retains its visible border.
- Messages with file or custom-navigation links stay with Paseo's renderer, preserving host navigation.

The plugin still targets official Paseo 0.8.0. No Paseo patch or daemon restart is required.
Linux hosts need `ps` (package `procps`) for process-tree cleanup.

## Install

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.1.3
```

If already pinned to an older tag:

```bash
paseo plugin remove advanced-markdown
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.1.3
```

`plugin update` continues tracking the installed ref; it cannot advance a fixed
older tag. Clients connected to that host receive the new plugin bundle.

## Validation

Targeted macOS tests cover real browser cleanup, font recovery, malformed fonts,
Chinese bold text, box raster output and file-link fallback. The released Paseo
compiler smoke exercises the bundled math and Mermaid implementations. The
release is gated on the full GitHub Actions suite on Ubuntu.

See [the QA record](../qa/2026-09-15-regression-fixes.md) for commands and platform
limits. Windows and Android remain untested; native UI was not retested for this
patch. The new inline Retry interaction requires follow-up device verification.
