# Advanced Markdown 0.3.1

Adds support for the Paseo **0.12** series and raises the minimum supported
version to **0.11**. Both app and daemon must satisfy **`>=0.11.0 <0.13.0`**.
Paseo 0.8–0.10 users should stay on v0.3.0. Paseo 0.13 remains excluded until
it is verified.

This release changes the compatibility declaration, development SDK baseline,
validation matrix, and installation documentation. Formula, Mermaid, code-block, table, and copying
behavior are unchanged. Code blocks and tables remain off by default.

The development compiler and SDK use official Paseo 0.11.0. CI validates that
baseline and runs a separate compatibility job with official 0.12.0.

See the [Paseo 0.12 compatibility record](../qa/paseo-0.12-compatibility.md)
for validation commands, results, and platform coverage. Native iOS/Android
devices and Windows were not tested for this release; phone-width browser
checks do not establish native device compatibility.

Install from Git:

```bash
paseo plugin add custyhs/paseo-advanced-markdown --ref v0.3.1
```

For an existing Git installation with `plugin update --ref` support:

```bash
paseo plugin update advanced-markdown --ref v0.3.1
```

The npm package is `paseo-advanced-markdown@0.3.1`. On Paseo 0.11, use v0.3.0
to roll back. Earlier supported Paseo versions (0.8–0.10) require v0.3.0;
v0.3.0 excludes Paseo 0.12 and cannot serve as its rollback release.
